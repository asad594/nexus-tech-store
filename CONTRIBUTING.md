# 🤝 Contributing to Nexus Tech Store

Thank you for your interest in contributing to Nexus Tech Store!

## Code Style Guidelines

- **Python (Backend)**: Follow PEP 8 guidelines. Include type annotations and docstrings for views, models, and serializers.
- **JavaScript / React (Frontend)**: Follow standard React functional component conventions. Use JSDoc comments for complex hooks and context providers.
- **Git Commit Messages**: Use standard Conventional Commit prefixes (`feat:`, `fix:`, `docs:`, `style:`, `refactor:`, `test:`).

## Development Workflow

1. Fork and clone the repository.
2. Create a feature branch: `git checkout -b feature/my-new-feature`
3. Run tests before submitting:
   - Backend: `python manage.py test store`
4. Open a Pull Request detailing changes made and testing verification.
